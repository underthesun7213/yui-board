## 규칙 (책임자, 2026-10-29~30)

- 윈도우 핀볼처럼 **플리퍼** 두 개로 구슬을 판에 붙잡아 둔다. 숫자 구멍은 그 점수(3·5·10)를 주고 구슬을 다시 내보내며, 범퍼는 1점.
- 발사: **발사** 버튼을 꾹 누르면 게이지가 1초 동안 올라가고 1초 동안 내려가기를 되풀이한다. 떼는 순간의 세기로 나간다. 약하면 되돌아와 다시 쏜다.
- 한 사람에 **세 개씩**, 번갈아. 합계가 많은 쪽이 이긴다. 동점이면 한 개씩 더. 공 하나는 40초가 지나면 플리퍼가 꺼진다.
- **다시 하기는 한 번만**: 유우키 「せやな、さっきのは練習やったもんな？ほな、ここからが本番や！」. 두 번째 결과로 확정.
- 버튼은 오락실 풍(둥근 돔 버튼: 왼쪽·발사·오른쪽).
- 유우키는 규칙 기반 게임 AI: 발사 세기는 35~95% 중 무작위, 내려오는 구슬을 82% 확률로 친다(0.24초).
- 끝나면 장면의 대사(이겼을 때 / 졌을 때)를 그대로 쓴다. 장면 #6 에서 받은 내기에 따라 **업적 일러스트**(주스 / 타코야키)를 얻는다 — 이기든 지든 같은 그림, 한 번만.
