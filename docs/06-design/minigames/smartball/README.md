## 규칙 (책임자, 2026-10-29~30)

- 윈도우 핀볼처럼 **플리퍼** 두 개로 구슬을 판에 붙잡아 둔다. 숫자 구멍은 그 점수(3·5·10)를 주고 구슬을 다시 내보내며, 범퍼는 1점.
- 발사: **발사** 버튼을 꾹 누르면 게이지가 1초 동안 올라가고 1초 동안 내려가기를 되풀이한다. 떼는 순간의 세기로 나간다. 약하면 되돌아와 다시 쏜다.
- 한 사람에 **세 개씩**, 번갈아. 합계가 많은 쪽이 이긴다. 동점이면 한 개씩 더. 공 하나의 시간이 다 되면 플리퍼가 꺼진다(아래 참고).
- **다시 하기는 한 번만**: 유우키 「せやな、さっきのは練習やったもんな？ほな、ここからが本番や！」. 두 번째 결과로 확정.
- 버튼은 오락실 풍(둥근 돔 버튼: 왼쪽·발사·오른쪽).
- 유우키는 규칙 기반 게임 AI: 발사 세기는 35~95% 중 무작위, 내려오는 구슬을 82% 확률로 친다(0.24초).
- 끝나면 장면의 대사(이겼을 때 / 졌을 때)를 그대로 쓴다. 장면 #6 에서 받은 내기에 따라 **업적 일러스트**(주스 / 타코야키)를 얻는다 — 이기든 지든 같은 그림, 한 번만.

## 첫 사용자 시험 뒤 (2026-10-30)

사용자 두 명의 평: 조작 안내가 없어 어떻게 하는지 모르겠다 / 너무 어렵다 / 상대 턴이 너무 길다.

- **조작 안내:** 시작 전에 3단계 안내(발사를 꾹 눌렀다 떼기 · 패들로 공 튕기기 · 맞혀서 점수). 판 위에 지금 할 일 말풍선(「발사를 꾹… 떼면 발사!」, 첫 공은 「패들로 튕겨 내!」), 발사 버튼이 깜빡인다.
- **쉽게:** 공이 느려졌다(중력 520→420, 최고 속도 1200→1000), 패들이 길어지고(58→63) 패들 사이 틈이 좁아졌다. 구멍이 조금 더 잘 잡는다. 발사 직후 5초 안에 떨어지면 한 번 다시 쏜다(볼 세이브). 유우키가 받아치는 확률 82%→72%.
- **시간:** 공 하나 20초에서 시작, 구멍에 넣을 때마다 +5초(10점 구멍 +8초). 유우키 턴은 1.7배 빠르게 흐른다.
- 패들이 내려올 때 아래에 있던 공을 바닥으로 밀어내던 버그를 고쳤다.
