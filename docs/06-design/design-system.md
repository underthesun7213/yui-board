이 문서는 **새로 디자인한 값이 아니라 프로토타입 코드에 이미 들어 있는 디자인 시스템을 추출한 것**이다. 모든 값은 `index.html` 에서 확인할 수 있고, 행 번호를 함께 적었다. 화면 ID 는 [IA](../03-ia/IA.md) §2 를 따른다.

## 1. 디자인 원칙 (코드에서 추론)

| # | 원칙 | 근거 |

| P-3 | **호버는 진짜 포인터에서만.** 탭한 뒤 호버 상태가 남지 않도록 `@media(hover:hover)` 로 분리 (단, 예외 2건 — §9 G-4) | 52–56행 주석 |

### 2.6 `body[data-top]` 과 상태 표시줄 채움

- `#statusfill` 은 높이 `env(safe-area-inset-top)` 의 고정 띠, z-index 60 (58–59행).
- 기본 `--ai`, `body[data-top="washi"]` 이면 `--washi` (60행).
- `render()` 가 `S.view` 가 `feed`/`cal`/`map`/`learn` 이면 `ai`, 그 외(상단 바 `.bar` 를 쓰는 화면)는 `washi` 로 설정한다 (1777행). 즉 **헤더가 있는 탭 루트(HOME-01, CAL-01, JP-01, MAP-01)는 남색, 상세 화면은 和紙색** 상태 표시줄이 된다. 초기값은 마크업의 `data-top="ai"` (471행).
- `apple-mobile-web-app-status-bar-style: black-translucent` (13행)와 짝을 이룬다. 매니페스트 `theme_color`·`background_color` 도 `#1D3E5C`.

### 7.4 없는 것

- 탭바·게시판 탭이 `role="tablist"`/`tab` 이 아니라 `aria-pressed` 버튼 묶음이다. 화면 낭독기에서 "탭 1/4" 로 읽히지 않는다.

## 8. 레이아웃 · 반응형 메모

- 컬럼 폭 430px 초과 화면에서 FAB 은 `right: calc(50% - var(--col)/2 + 16px)` 로 컬럼 안쪽에 붙고, 462px(= 430 + 32) 이하에서는 `right:16px` (455, 460행). `--col` 을 바꾸면 이 미디어쿼리 값도 같이 바꿔야 한다.
- 탭바·시트는 `position:fixed` + `max-width:var(--col)` 로 컬럼에 맞춘다 (445, 427행). 탭바는 `left` 지정이 없어 `body` 의 `justify-content:center` 에 의존한다.
- **한국어 기준 고정 폭 점검** (CLAUDE.md): `.facts dt` 78px — "참가 예정" 12.5px ≈ 55px 로 수용. `.ev .clock` 38px — 시각만 표시라 언어 무관. `.langmenu` min-width 172px — 안내문은 줄바꿈. 탭바는 4등분이라 "캘린더" 문제 없음.
- **헤더 `.crest` 한 줄 넘침 위험**: 로고(30) + 제목·부제(부제 "GLOBAL COMMONS 結 -YUI-" 10.5px + 자간 ≈ 150) + 언어 버튼(≈ 80) + ⇄ ⚑(≈ 33×2 + 8) + gap 11×4 + 좌우 36 ≈ 420px. `flex-wrap`·`min-width:0`·말줄임이 없어 **360px 이하 폰에서 넘칠 가능성**이 높다 (추정, 실기 확인 필요).
