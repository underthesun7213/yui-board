# 대화 게임(레벨 8) 스토리보드 — 채우는 양식

책임자가 이 양식을 **한국어로** 채운다. 일본어 대사·선택지·피드백(ja·en·ko)·후리가나·그림 프롬프트·음성은 이 양식을 받아 Claude 가 만든다(그 뒤 책임자 검토). 칸을 다 채우지 못해도 된다 — 빈칸은 Claude 가 초안을 넣고 표시한다.

> 지금 게임(유우키·아야노, 오사카·교토 2루트)의 실제 대본은 [`game-script.md`](game-script.md). 아래 **예시** 줄은 거기서 가져왔다.

## 1. 그림 방식 — 하나 고르기

Gemini 는 같은 인물을 여러 장에 똑같이 그리는 것을 잘 못한다(D36). 그래서 방식에 따라 결과가 다르다.

- [ ] **A. 장면마다 그림 한 장** (지금 방식). 장면 그림에 인물이 들어가지만, 장마다 얼굴·옷이 조금씩 달라질 수 있다.
- [ ] **B. 캐릭터 스탠딩 1장 + 장면별 배경** — 인물은 한 번만 그리고(투명 배경), 장면마다 배경 위에 겹친다. 인물이 항상 같아 보인다. **앱 코드 수정이 필요**하다(겹쳐 그리기, 표정을 바꾸려면 표정별 그림).
- [ ] **C. 배경만** — 인물은 그리지 않고 장소만 보여 준다. 가장 빠르고 일관성 문제가 없다.

표정을 바꾸고 싶으면(B): 캐릭터마다 필요한 표정 — 예: 기본 / 웃음 / 곤란 / 놀람

규칙:
- 선택지는 2~3개, 그중 ○ 가 최소 1개.
- 피드백은 고른 뒤에 보인다 — "왜" 칸이 그 초안이 된다.
- **선택에 따라 다음 장면이 달라지게(분기)** 하고 싶으면 장면 블록에 `→ 다음 장면: ___` 을 적는다. 지금 게임은 루트 안에서 장면이 한 줄로 이어지므로, 분기는 **앱 코드 수정이 필요**하다.
- **업적 일러스트**를 주는 장면에는 장면 블록에 `→ 업적: (일러스트 이름) — (조건)` 을 적고, §5 표에도 한 줄 넣는다.
- **미니게임**은 장면 블록에 이름으로 적는다(예: 유우키 미니게임). 이미 있는 것: 유우키 미니게임(`docs/06-design/minigames/yuki-minigame/`). 새로 만들어야 하는 것은 §5 아래 목록에.

## 5. 업적 일러스트

엔딩 카드 대신 **업적 일러스트**를 모은다.

- 게임 **중간중간**, 표의 조건을 채운 순간 해금된다(엔딩까지 기다리지 않는다). 해금되면 "업적 획득" 알림과 함께 그림을 보여 주고, 레벨 목록의 컬렉션에 남는다.
- **이미 얻은 일러스트는 다시 얻지 않는다.** 같은 조건을 다시 채우면 알림 없이 지나간다(또는 "이미 획득"만 표시). 기록은 기기에 남는다(지금 엔딩 카드와 같은 방식).
- 그림 규격: 가로 3:2, 글자 없음. 루트 캐릭터는 만화와 같은 화풍.

1. 대사·선택지를 자연스러운 일본어로 쓰고, 피드백을 ja·en·ko 세 언어로 쓴다. 한자에는 후리가나 표시(`{漢字|かな}`)를 단다.
2. 캐릭터 시트와 장면·업적 일러스트 프롬프트를 쓰고, Gemini 로 그림을 만들어 `Downloads\yunabi-comics` 에 저장한 뒤 규격(장면 4:3, 업적 3:2)에 맞춰 넣는다.
3. 대본을 `docs/06-design/game-script.md` 형식으로 다시 보여 드린다 → 확인 뒤 앱에 넣는다.
4. 대사 음성(Azure)을 만든다.
5. 그림 방식 B 나 분기를 고르면, 그 앱 수정도 함께 한다.
