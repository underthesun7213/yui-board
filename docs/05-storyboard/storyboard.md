# 5단계 · 화면설계서 (와이어프레임 + 디스크립션)

| | |
|---|---|
| 상태 | 초안 v0.1 |
| 기준 | 375 × 812 (iPhone 기준), 앱 본문 폭 최대 430px, 한국어 UI |
| 근거 | `index.html` 뷰 함수의 실제 배치. 실제 화면 캡처는 [QA 리포트](../08-qa/qa-report.md) 의 스크린샷 참조 |
| 이전 단계 | [기능명세서](../04-spec/functional-spec.md) |
| 다음 단계 | [디자인 시스템](../06-design/design-system.md) |

**읽는 법:** 와이어프레임의 ①②③ 번호가 오른쪽(아래) 디스크립션 번호와 대응한다. 기능 ID(FN-…)는 기능명세서를 가리킨다.
⚠ 는 개선이 필요한 지점, ✚ 는 실서비스에서 새로 추가할 요소다.

> 프로토타입(`index.html`)이 이미 고해상도 시안 역할을 한다. 이 문서는 그 화면을 흑백 뼈대로 다시 정리하고,
> 각 요소의 동작·조건을 붙인 것이다. 새로 필요한 화면(AUTH-01, ME-01)은 프로토타입에 없으므로 이 문서가 처음 그린다.

|---|---|---|

| ⑥ | 교환 요청 | 모임·나눔·장터·분실물 글에만. 보낸 뒤 "이미 요청을 보냈습니다"로 비활성 |
| ⑦ | 댓글 | 익명 번호 / 글쓴이, 시간, 신고(⚑). 글쓴이 답글은 들여쓰기. ⚠ 댓글에는 원문 보기 없음 |
| ✚⑧ | 댓글 입력 | 하단 고정 입력창. 댓글의 ⚑ 옆에 "답글"을 두어 1단계 대댓글 (PRD B-6) |
