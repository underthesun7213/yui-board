# ADR-0003 · 클라이언트는 단일 `index.html` 을 유지하고 데이터 계층을 그 안에 둔다

| | |
|---|---|
| 상태 | ADR-0013으로 대체됨 |
| 날짜 | 2026-10-11 |
| 근거 | CLAUDE.md "The shape of the code", PRD §8 구조·품질, 핸드오프 §1.2, FN-HOME-01-1, BL-30, BL-53, TC-L-02 |
| 관련 | [RFC-0001 §6](../architecture/rfc/0001-m1-backend-foundation.md#6-단일-파일-클라이언트에-데이터-계층-붙이기), [conventions.md](../architecture/conventions.md) |

## 배경

CLAUDE.md 는 "`index.html` 한 파일, 빌드·프레임워크·번들러 없음 — 합의 없이 바꾸지 않는다"고 정한다. 실데이터 연결(M2~M3)에는 인증, `fetch`, 로딩·오류 상태가 새로 필요하다. 이것을 위해 빌드 도구나 프레임워크로 옮길지 정해야 한다. 현재 파일은 약 1,900줄이다.

## 결정

1. **단일 파일과 기존 구조를 유지한다.** 이 ADR 은 이전을 제안하지 않는다.
2. 스크립트에 `CFG`(공개 URL·publishable 키), `API`(fetch 래퍼), `AUTH`(세션), `load*()`(화면별 로더) 블록을 **데이터 상수 다음, `S` 앞**에 둔다. 정의만 있고 부수 효과가 없다.
3. **Supabase JS SDK 를 쓰지 않는다.** PostgREST·Auth·Functions 를 `fetch` 로 부른다.
4. 뷰 함수는 동기·순수를 유지한다. 로더가 `S` 와 데이터 배열을 채운 뒤 `render()` 를 부른다. 로딩·오류는 `S.net` 으로 표현한다.
5. mock 상수(`POSTS`, `EVENTS`, `PLACES` …)는 **이름을 유지하고 fixture 로 남긴다.** `CFG.url` 이 비어 있으면 fixture 모드로 동작한다 → CLAUDE.md 헤드리스 하네스가 그대로 돈다.
6. 세션 복원·첫 로드 같은 부수 효과는 모두 `/* Manifest shortcuts` 주석 **아래**에 둔다(하네스가 그 지점부터 잘라낸다).
7. 비동기 로더는 완료 후 `render()` 를 직접 부르지 않고 `refresh()` 를 부른다: `S.view === "map"` 이면 `updateMap()`, 아니면 `render()`. `render()` 는 `#main` 을 바꿔 Leaflet 지도를 떼어 내고 `LMAP` 이 남아 있어 다시 만들지 않는다(`index.html:1781`, `:1788-1789`, BUG-01 과 같은 원인).

## 고려한 대안

| 대안 | 기각 이유 |
|---|---|
| Vite + 프레임워크 이전 | CLAUDE.md 제약. 배포가 빌드 산출물 관리로 바뀌고 GitHub Pages 루트 배포 규칙이 깨진다. 지금 규모에서 이점이 비용보다 작다 |
| SDK 를 CDN 으로 추가 | 고정 버전·SRI·CSP 예외가 생기고, 하네스에 전역 스텁이 필요하다. 필요한 REST 는 몇 개뿐이다 |
| 데이터 계층을 별도 `api.js` 로 분리 | "한 파일" 원칙과 충돌. 하네스는 `index.html` 의 `<script>` 만 읽는다 |

## 결과

- 좋은 점: 배포·테스트 방식이 바뀌지 않는다. 프로토타입 화면이 그대로 실서비스 화면이 된다.
- 나쁜 점: 토큰 갱신·재시도를 직접 쓴다. 파일이 커진다(데이터 계층 300~500줄 *추정*).
- **재검토 조건:** 파일 4,000줄 초과, 데이터 계층 500줄 초과, 타입 검사·단위 테스트 필요성이 합의될 때. 그때는 새 ADR 로 이전을 제안하고 이 ADR 을 "대체됨"으로 바꾼다.

## 열린 질문

| # | 질문 |
|---|---|
| F-Q1 | Leaflet·markercluster 를 저장소에 두어 같은 출처로 서빙할지(오프라인 셸 포함), cdnjs + SRI 로 둘지 (RFC R-4). 저장소에 두는 것이 "단일 파일" 원칙에 어긋나지 않는지 합의 필요 |
