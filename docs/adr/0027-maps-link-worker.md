## 배경

장소는 대개 그 자리에 서서가 아니라 방에 돌아와서 등록한다. 그때 지도에서 핀을 찾아 누르는 것이 등록의 병목이다. 사람들은 이미 그 장소를 구글 지도에서 보고 있고, 휴대폰 앱의 **공유 → 링크 복사**는 `maps.app.goo.gl/…` **짧은 링크**를 준다.

2026-11-02 에 실제 짧은 링크 6개를 열어 본 결과:

- 모두 `302` 로 `www.google.com/maps/…` 긴 링크로 간다(한 번).
- 5개는 긴 링크에 장소 좌표(`!3d…!4d…`)나 화면 중심(`@위도,경도`)이 있다.
- 1개(`utm_source=mstt_1&entry=gps`)에는 좌표가 **없다**. 그 페이지 HTML 에도 장소 좌표는 없고(화면은 JS 가 그린다), 서버가 보는 지도 중심은 요청한 IP 의 위치다.

브라우저는 CORS 때문에 다른 사이트의 리다이렉트를 따라갈 수 없다.

## 결정

1. **붙여 넣을 수 있는 것** — 장소 폼의 "Google 지도에서 찾기" 칸:
   - 숫자 두 개 `34.82, 135.65` (구글 지도에서 길게 누르거나 오른쪽 클릭하면 복사됨)
   - 긴 링크: `!3d…!4d…`(장소 핀) → `q=`·`query=`·`ll=` → `@위도,경도`(화면 중심) 순
   - 짧은 링크: 아래 Worker 가 연다
   해석은 `src/domain/maps-coords.ts` 의 순수 함수 하나로, 앱과 Worker 가 같이 쓴다.
2. **핀은 옮기고 되돌릴 수 있게.** 찾으면 핀을 그 자리로 옮기고 지도도 그리로 간다. "되돌리기"로 원래 핀으로 돌아간다. 폼을 저장하기 전에는 아무것도 저장되지 않는다. 일본 밖이면 옮기지 않는다. 서버의 위치 규칙(`app.pref_of`)이 그대로 마지막 검사다. 짧은 링크로 찾았고 링크 칸이 비어 있으면 그 링크를 링크 칸에도 넣는다.
3. **Worker** (`worker/index.ts`, `wrangler.app.jsonc` 의 `main`) — `run_worker_first: ["/api/*"]` 라 그 밖의 모든 요청은 지금처럼 정적 자산이 바로 답한다.
   - `GET /api/maps-link?u=` 하나. `u` 는 `https://maps.app.goo.gl/<4~64자 id>` (뒤 `?g_st=…` 허용)만. id 만 꺼내 그 주소 하나를 `redirect: 'manual'` 로 요청하고, **응답 본문은 읽지 않고** `Location` 헤더만 읽는다. 그것이 구글 지도 주소일 때만 좌표를 뽑는다. goo.gl 끼리 한 번 더 넘기는 것까지(최대 2번). 그러니 아무 주소나 대신 여는 통로(오픈 프록시·SSRF)가 아니다.
   - 답: `{status:'ok',lat,lng}` · `none`(좌표 없는 링크) · `invalid`(400) · `limit`(429) · `fail`(502). `cache-control: no-store`.
   - 남용 한도: Workers 레이트 리밋 바인딩 `LINKS`, IP 당 1분 20회.
   - 저장·로그 없음. 보내는 것은 사용자가 붙여 넣은 공개 링크뿐(개인정보 아님). 같은 출처라 CSP `connect-src` 는 그대로.
4. **좌표 없는 링크**는 고칠 수 없다고 정직하게 말한다: "Google 지도에서 그 자리를 길게 누르고 위에 나오는 숫자를 붙여 넣어 주세요." 구글의 비공개 내부 API 를 긁거나 유료 Places API(키·결제)를 쓰지 않는다.

## 대안

- **긴 링크와 숫자만**(서버 없음): 휴대폰 공유 링크가 안 된다 — 가장 흔한 경우를 놓친다.
- **Supabase Edge Function**: 다른 출처라 CSP·CORS 가 늘고, DB 프로젝트에 무관한 공개 함수가 생긴다. 앱 도메인의 Worker 가 더 좁다.
- **Places/Geocoding API**: 정확하지만 키·결제 계정·비용. 필요 없다.

## 결과

- 배포는 지금처럼 `wrangler deploy -c wrangler.app.jsonc` 하나(런북 §7.3). Worker 코드가 같이 올라간다.
- e2e 는 `vite preview` 라 Worker 가 없다 — 테스트가 `/api/maps-link` 를 대신 답한다. Worker 자체는 `tests/unit/maps-link.test.ts` 가 본다.
- ZAP 스캔(B-17) 범위에 `/api/maps-link` 가 들어간다.
