## 이 프로젝트에 맞춘 방식

- **역순으로 만든 문서가 있다.** 프로토타입(6단계 산출물에 해당)이 먼저 있었기 때문에, 3~6단계 문서는 코드에서 거꾸로
  추출해 정리했다. 그래서 각 문서에 "현재 동작"과 "목표 동작"을 나눠 적었다.
- **스타트업식 PRD + SI식 화면설계서를 같이 쓴다.** PRD 에 요구사항을 모으고, 화면설계서는 와이어프레임에 디스크립션을 붙인다.
- **5~8단계는 마일스톤(PRD §10)마다 반복한다.** 다음 반복의 입력은 [백로그](09-release/backlog.md) 다.
- **사람이 필요한 단계는 결과를 지어내지 않았다.** 인터뷰와 사용성 테스트는 가이드·계획만 있고, 수행 후 채운다.

## QA 재실행

QA 리포트의 헤드리스 실행에 쓴 Playwright 스크립트는 저장소에 넣지 않았다. 이 저장소는 테스트 러너를 두지 않기로 했기
때문이다(CLAUDE.md). 재현이 필요하면 [QA 리포트](08-qa/qa-report.md) 의 절차대로 다시 작성하거나, 테스트 도구 도입을 따로 결정한다.
