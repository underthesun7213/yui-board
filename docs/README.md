# YUI Board 기획 문서

9단계 기획 프로세스에 맞춰 정리한 산출물이다. 단계마다 폴더가 하나씩 있다.

| 단계 | 하는 일 | 산출물 | 상태 |
|---|---|---|---|
| 1. 리서치·분석 | 시장·경쟁사 조사, 사용자 인터뷰, 문제 정의 | [리서치 보고서](01-research/research.md) — 문제 정의, 경쟁·대체재 분석, 페르소나, 사용자 여정 지도, 인터뷰 가이드 | 초안. **인터뷰 미수행** — 페르소나·여정은 가설 |
| 2. 요구사항 정의 | 무엇을 왜 만드는지, 목표·범위·우선순위 | [PRD](02-requirements/PRD.md) | v0.3, 검토 2회 |
| 3. 정보구조 설계 | 메뉴 구조, 화면 간 흐름 | [IA·유저 플로우](03-ia/IA.md) — 메뉴 구조도, 화면 목록(화면 ID), 플로우 F-1~F-7 | 초안 |
| 4. 기능 정의 | 동작, 조건, 예외, 정책 | [기능명세서](04-spec/functional-spec.md), [정책 정의서](04-spec/policy.md) | 초안 |
| 5. 화면 설계 | 와이어프레임 + 디스크립션 | [화면설계서](05-storyboard/storyboard.md) | 초안 |
| 6. UI 디자인 | 색·타이포·컴포넌트 | [디자인 시스템](06-design/design-system.md). 고해상도 프로토타입은 [`index.html`](../index.html) | 초안 (현 코드에서 추출) |
| 7. 개발 핸드오프 | 스펙·에셋·API 명세 | [핸드오프 문서](07-handoff/handoff.md) — 화면↔데이터 매핑, 데이터 모델, API, 에셋 목록 | 초안 |
| 8. QA·검증 | 테스트 케이스, QA, 사용성 테스트 | [테스트 계획](08-qa/test-plan.md), [QA 리포트](08-qa/qa-report.md), [사용성 테스트 계획](08-qa/usability-test-plan.md) | 프로토타입 대상 QA 수행. **사용성 테스트 미수행** |
| 9. 출시·운영 | 배포, 지표, 개선 | [출시·운영 계획](09-release/release-plan.md) — 릴리스 노트, 지표 대시보드 정의, [개선 백로그](09-release/backlog.md) | 출시 전 |

## 이 프로젝트에 맞춘 방식

- **역순으로 만든 문서가 있다.** 프로토타입(6단계 산출물에 해당)이 먼저 있었기 때문에, 3~6단계 문서는 코드에서 거꾸로
  추출해 정리했다. 그래서 각 문서에 "현재 동작"과 "목표 동작"을 나눠 적었다.
- **스타트업식 PRD + SI식 화면설계서를 같이 쓴다.** PRD 에 요구사항을 모으고, 화면설계서는 와이어프레임에 디스크립션을 붙인다.
- **5~8단계는 마일스톤(PRD §10)마다 반복한다.** 다음 반복의 입력은 [백로그](09-release/backlog.md) 다.
- **사람이 필요한 단계는 결과를 지어내지 않았다.** 인터뷰와 사용성 테스트는 가이드·계획만 있고, 수행 후 채운다.
