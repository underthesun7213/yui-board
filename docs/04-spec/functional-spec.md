**읽는 법**
- 기능 ID 는 `FN-<화면 ID>-<번호>`. 요구사항 ID(B-1 등)는 [PRD](../02-requirements/PRD.md) 를 가리킨다.
- **현재 동작**은 프로토타입이 실제로 하는 일, **목표 동작**은 실서비스에서 해야 할 일이다. 둘이 같으면 목표 칸을 비웠다.
- ⚠ 는 명세 작성 중 발견한 결함 또는 결정이 필요한 지점이다.
