## 1. 무엇이 바뀌나

MLP v1.3 은 서버 없이 **직접 넣은 장소·일정**을 보여주는 앱이었다. v2.0 은 다음 세 가지가 달라진다.

1. **장소와 일정은 사용자가 등록해 모두가 함께 본다.** 초기 데이터는 없다. 서버가 다시 필요하다.
2. **이름은 YUNABI**, 로고는 연파랑 나비.
3. **코드를 일반적인 프로젝트 구조(프레임워크, 빌드, 테스트 러너)로 다시 만든다.** 과제용으로 두었던 제약은 없앤다.

## 3. 목표 / 비목표

### 목표

- G1. 로그인 화면 없이 바로 쓰고, 바로 등록한다 (D17)
- G2. 한 사람이 등록한 장소·일정을 모두가 본다 (D16)
- G3. 잘못된 등록은 사용자 신고만으로 빨리 사라지고, 관리자가 최종 판단한다 (D18)
- G4. 일본어 만화·게임과 엔딩 컬렉션은 v1.3 그대로 (컬렉션은 기기에 저장)
- G5. 일반적인 구조로 유지보수할 수 있다: 모듈, 타입, 자동 테스트, CI (D19)
- G6. 3개 언어 UI 유지

### 비목표

| 기능 | 처리 |
|---|---|
| 게시판, 댓글, 프로필 교환 (v0.4) | 계속 제외 |
| 등록 내용 자동 번역 | 하지 않음 — 쓴 언어 그대로 보인다 (Q-Y4) |
| 일정 참가 신청·인원 집계 | 하지 않음 (v1.3 D9 유지) |

## 7. 기술 방향 (D19)

설계는 architect 가 기술 검토서·RFC·ADR 로 정한다. 기획이 요구하는 조건만 적는다.

| 조건 | 내용 |
|---|---|
| 구조 | 프레임워크 + 타입 + 빌드 도구. 모듈로 나뉜 코드 |
| 테스트 | 저장소 안의 단위 테스트 + E2E 테스트, `npm test` 로 실행. CI 에서 자동 실행 |
| 품질 | 린트·포맷터, 타입 검사를 CI 에서 |
| 백엔드 | 익명 계정, 행 단위 권한(내 항목만 수정), 서버 측 검증·빈도 제한, 신고 집계 → 자동 숨김을 지원할 것. 무료 또는 저비용 |
| 호스팅 | 정적 호스팅 가능 (현재 GitHub Pages) |
| 호환 | v1.3 의 기기 저장(`yui.v1.*`)을 그대로 읽는다 |
| 지도 | Leaflet 과 도도부현 경계 데이터는 계속 쓴다 (ADR-0012) |
| 기존 규칙 | CLAUDE.md 의 과제용 규칙은 없앤다. 남길 것(3개 언어 문자열, 데이터 이스케이프, 한국어 기준 폭, 위치 사용 전 안내, 지도 한 번만 생성)은 일반 원칙으로 다시 쓴다 |

| Y-4 | 개인정보처리방침, 배포 | Y-P4, 실기기 확인 |

## 9. 리스크

| 리스크 | 대응 |
|---|---|
| 초기 데이터가 0이라 처음 쓰는 사람에게 지도·달력이 비어 보인다 | 빈 상태 안내에서 등록을 권한다. 책임자·RA 가 첫 등록을 맡을지 결정 (Q-Y1) |
| 익명 자동 계정이라 장난 등록·신고 남용이 쉽다 | 빈도 제한, 자동 숨김 기준, 관리자 복원 (Y-A3, Y-A4, Y-R4) |
| 자동 숨김을 악용해 정상 항목을 지울 수 있다 | 관리자 복원 + 신고 계정 조건 (Y-A4) |
| 집·방 위치가 장소로 등록될 수 있다 | 현재 위치 등록 경고 (Y-M5), 신고 사유 "개인정보 노출" |
| 재작성 중 v1.3 기능이 퇴행한다 | Y-1 완료 기준을 기존 브라우저 검사로 |
| 그림 제작이 늦어진다 | 회색 이미지로 출시 가능 (D15) |
