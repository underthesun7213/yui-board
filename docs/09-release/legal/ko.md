## 이용약관

### 제1조 (서비스)
YUNABI(이하 "서비스")는 結 -YUI- 거주자를 위해 일본어 학습, 생활에 필요한 장소 지도, 일정 달력을 제공합니다. 운영자는 박주하(개인)입니다. 누구나 볼 수 있으며, 장소·일정 등록과 신고에는 가입이 필요 없습니다. 처음 등록할 때 익명 계정이 자동으로 만들어집니다.

### 제2조 (익명 계정)
익명 계정은 사용하는 브라우저에 묶입니다. 브라우저 데이터를 지우거나 기기를 바꾸면 전에 등록한 항목을 고치거나 지울 수 없습니다. 이때 삭제가 필요하면 아래 문의처로 요청해 주세요.

### 제3조 (등록하는 내용)
등록한 장소와 일정은 모든 사용자에게 공개됩니다. 다음은 등록하지 마세요.
- 자신이나 다른 사람의 집·방 위치, 이름, 연락처 등 개인을 알아볼 수 있는 정보
- 광고·스팸, 같은 내용의 반복 등록
- 법령이나 공서양속에 어긋나는 내용, 다른 사람의 권리(저작권·초상권·명예 등)를 침해하는 내용
- 사실과 다르다는 것을 알면서 쓰는 정보

### 제4조 (등록한 내용의 권리)
등록한 내용의 권리는 등록한 사람에게 있습니다. 등록한 사람은 운영자가 서비스 안에서 그 내용을 보여 주고, 서비스 운영(백업·복구 포함)에 필요한 범위에서 복제·보관하는 것을 허락합니다.

### 제5조 (신고와 운영자 조치)
사용자는 항목을 신고할 수 있습니다. 서로 다른 계정 3개에서 신고된 항목은 자동으로 숨겨지고 운영자가 확인합니다. 운영자는 이 약관에 어긋난다고 판단한 항목을 숨기거나 삭제하고, 계정의 쓰기를 정지할 수 있습니다.

### 제6조 (이용 제한)
짧은 시간에 너무 많이 쓰는 것을 막기 위해 계정과 접속 단위로 쓰기 횟수를 제한합니다(예: 계정당 하루 장소 등록 15건). 자동화된 대량 등록이 보이면 확인 절차(CAPTCHA)를 켤 수 있습니다.

### 제7조 (정보의 정확성과 책임)
장소·일정 정보는 사용자가 등록한 것이며, 운영자는 그 정확성(영업 여부, 시간, 위치 등)을 보증하지 않습니다. 서비스는 무료이며 예고 없이 바뀌거나 멈출 수 있습니다. 운영자는 고의 또는 중대한 과실이 있는 경우를 제외하고, 서비스 이용으로 생긴 손해에 책임을 지지 않습니다.

### 제8조 (변경)
운영자는 이 약관을 바꿀 수 있으며, 바뀐 약관은 서비스 안에 게시한 때부터 효력이 생깁니다. 중요한 변경은 앱 안에서 미리 알립니다.

### 제9조 (준거법·관할)
이 약관은 일본법을 따릅니다. 서비스에 관한 분쟁은 운영자의 주소지를 관할하는 지방법원을 제1심 전속 관할 법원으로 합니다.

## 개인정보처리방침

### 1. 운영자
박주하(개인). 운영자의 주소는 요청하시면 지체 없이 알려 드립니다.

### 2. 모으는 정보

| 무엇 | 언제 | 왜 |
|---|---|---|
| 익명 계정 ID (무작위 값) | 처음 등록하거나 신고할 때 | 내 항목 수정·삭제, 이용 제한, 신고 처리 |
| 등록한 장소·일정의 내용과 작성 언어, 등록·수정 날짜 | 등록·수정할 때 | 서비스 제공 (모두에게 공개) |
| 장소 설명, 일정의 제목·장소·내용의 자동 번역문 (영어·일본어·한국어 중 나머지 두 언어) | 등록·수정한 뒤 | 다른 언어 사용자에게 보여 주기 (공개, 원문도 볼 수 있음) |
| 신고 (대상, 이유) | 신고할 때 | 자동 숨김과 운영자 확인 |
| 쓰기 기록 (언제 무엇을 썼는지) | 쓸 때 | 하루 한도 관리 |
| 접속 IP 주소의 가명 처리 값 (매일 바뀌는 비밀 값을 섞은 해시) | 쓰기 요청 때 | 부정 이용 방지 |
| 운영자 조치 기록 | 운영자가 숨김·삭제·복원·정지할 때 | 기록과 감사 |

**모으지 않는 정보:** 사용자의 이름, 이메일 주소, 현재 위치.

### 3. 위치
현재 위치는 사용자가 허락한 때에만 기기 안에서 지도 중심과 도보 시간 계산에 쓰고, 서버로 보내지 않습니다. 서버로 가는 좌표는 등록한 장소의 좌표뿐입니다. 다만 지도 그림(타일)을 불러올 때 보고 있는 지역의 타일 번호가 OpenStreetMap 의 타일 서버로 가며, 확대할수록 지역이 좁혀집니다.

### 4. 자동 번역
장소 설명과 일정의 제목·장소·내용은 등록·수정한 뒤 Microsoft 의 기계 번역(Azure AI Translator)으로 나머지 두 언어로 번역해 보관하고, 보는 사람의 화면 언어로 보여 줍니다("자동 번역" 표시, 원문 보기 가능). Microsoft 에는 이 글과 언어만 보내며, 장소 이름, 위치, 일정의 날짜·시간, 계정, 등록한 사람의 정보는 보내지 않습니다. Microsoft 는 텍스트 번역으로 보낸 글을 저장하지 않는다고 밝히고 있습니다.

### 5. 방문 통계
앱 이용 현황을 알기 위해 Cloudflare Web Analytics 를 씁니다. 쿠키를 쓰지 않고, 본 화면, 대략적인 국가, 브라우저·기기 종류, 로딩 속도만 집계하며, 개인을 식별하거나 사이트를 넘어 추적하지 않습니다.

### 6. 기기에 남는 정보
언어 설정, 모은 카드, 위치 사용 여부는 브라우저 저장소(localStorage)에만 있고 서버로 가지 않습니다. 브라우저 데이터를 지우면 사라집니다.

### 7. 접속 기록
서비스를 제공하는 사업자의 서버에는 접속 기록(IP 주소, 시각, 브라우저 정보 등)이 남을 수 있습니다. 특히 계정 서비스(Supabase Auth)의 기록에는 IP 주소가 그대로 남습니다. 보관 기간은 각 사업자의 정책을 따릅니다.

### 8. 확인 절차 (CAPTCHA)
자동화된 공격이 있을 때 운영자는 Cloudflare Turnstile 확인을 켤 수 있습니다. 켜져 있는 동안에는 첫 등록 때 Cloudflare 가 사람과 프로그램을 구별하기 위해 브라우저·기기 정보를 처리합니다. 평소에는 꺼져 있습니다.

### 9. 보관 기간

| 무엇 | 보관 |
|---|---|
| 장소·일정 | 지울 때까지. 지운 항목은 30일 뒤 완전히 삭제. 끝난 일정은 1년 뒤 삭제 |
| 익명 계정 | 마지막 쓰기·신고에서 1년 뒤 삭제. 계정이 지워져도 등록한 장소는 남습니다(주인 없는 항목, 수정 불가) |
| 신고, 운영자 조치 기록 | 1년 |
| 쓰기 기록 | 48시간 |
| IP 가명 처리 값 | 쓰기 횟수 판단용은 1시간, 보안 기록에서는 48시간 뒤 삭제 (보안 기록 자체는 90일) |
| 자동 번역문 | 원문과 같이: 글을 고치면 바로 삭제하고 새로 번역, 장소·일정을 지우면 바로 삭제 |
| 백업 | 주 1회, 암호화해 90일 보관. 백업에는 매일 바뀌는 비밀 값이 없어 IP 가명 처리 값을 되돌릴 수 없습니다 |

### 10. 처리 위탁과 해외 이전
서비스 운영을 위해 다음 사업자에게 개인정보 처리를 맡기고 있으며, 모두 해외 사업자입니다.

| 사업자 | 맡기는 일 | 데이터 위치 |
|---|---|---|
| Supabase, Inc. (미국) | 데이터베이스, 익명 계정 | 도쿄 리전 |
| Cloudflare, Inc. (미국) | 앱 전송, 방문 통계, (켤 때만) Turnstile | 세계 각지의 전송망 |
| GitHub, Inc. (미국) | 소스 코드, 암호화된 백업 보관(비공개) | 미국 등 |
| Microsoft Corporation (미국) | 장소 설명과 일정 글의 자동 번역 (글만 보내며 저장되지 않음) | 일본 동부(도쿄) 리소스에서 처리 |
| OpenStreetMap 재단 (영국) | 지도 그림 (사용자의 브라우저가 직접 요청) | 영국·유럽 등 |

운영자는 이 사업자들이 일본 개인정보보호법이 정하는 기준에 맞는 체제를 갖추고 있음을 확인한 뒤 맡기고 있습니다. 각국의 개인정보 보호 제도는 일본 개인정보보호위원회가 제공하는 정보를 참고해 주세요.

위 위탁 외에는 법령에 따른 경우를 제외하고 개인정보를 제3자에게 제공하지 않습니다. 광고는 없습니다. 분석 도구는 쿠키를 쓰지 않는 Cloudflare Web Analytics 뿐입니다.

### 11. 안전 관리
사용자의 기기에서는 데이터베이스를 직접 읽거나 쓸 수 없고, 서버의 검사를 거친 기능을 통해서만 씁니다. 등록한 사람은 다른 사용자에게 보이지 않으며, 운영자도 가명 계정 ID 만 봅니다. 관리자 로그인에는 비밀번호와 2단계 인증을 씁니다. 백업은 암호화합니다.

### 12. 열람·정정·삭제 요청
계정이 익명이라 운영자는 요청한 사람이 그 계정의 주인인지 확인할 수 없습니다. 그래서 자기 항목은 같은 브라우저의 "내가 올린 것"에서 직접 고치거나 지우는 것이 기본입니다. 기기를 잃어버렸거나 앱을 쓰지 않는 분(예: 가게 주인, 집이 등록된 분)은 문의처로 항목의 이름과 위치를 알려 주시면 운영자가 확인해 처리합니다.

### 13. 변경
이 방침을 바꾸면 서비스 안에 게시합니다.
