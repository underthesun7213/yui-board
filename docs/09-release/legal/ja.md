## 利用規約

### 第1条（サービス）
YUNABI（以下「本サービス」）は、結 -YUI- の居住者向けに、日本語学習、生活に役立つ場所の地図、予定のカレンダーを提供します。運営者はバク・ジュハ（個人）です。どなたでも閲覧できます。場所・予定の登録や通報に会員登録は不要で、最初の登録時に匿名アカウントが自動で作られます。

### 第2条（匿名アカウント）
匿名アカウントはお使いのブラウザに結び付きます。ブラウザのデータを消したり端末を変えたりすると、以前に登録した項目を編集・削除できなくなります。その場合に削除が必要なときは、お問い合わせ（第3章）からご依頼ください。

### 第3条（登録する内容）
登録した場所と予定は、すべての利用者に公開されます。次のものは登録しないでください。
- 自分や他人の自宅・部屋の位置、氏名、連絡先など、個人を特定できる情報
- 広告・スパム、同じ内容の繰り返し登録
- 法令や公序良俗に反する内容、他人の権利（著作権・肖像権・名誉など）を侵害する内容
- 事実と異なると知りながら書く情報

### 第4条（登録した内容の権利）
登録した内容の権利は登録した方に残ります。登録した方は、運営者が本サービスの中でその内容を表示し、本サービスの運営（バックアップ・復旧を含む）に必要な範囲で複製・保存することを許諾します。

### 第5条（通報と運営者の措置）
利用者は項目を通報できます。異なる3つのアカウントから通報された項目は自動的に非表示になり、運営者が確認します。運営者は、本規約に反すると判断した項目を非表示または削除し、アカウントの書き込みを停止することがあります。

### 第6条（利用の制限）
短時間の大量の書き込みを防ぐため、アカウントと接続ごとに書き込みの回数を制限しています（例: 1アカウントにつき1日15件の場所登録）。自動化された大量登録が見られる場合、確認手続き（CAPTCHA）を有効にすることがあります。

### 第7条（情報の正確性と責任）
場所・予定の情報は利用者が登録したものであり、運営者はその正確性（営業の有無、時間、位置など）を保証しません。本サービスは無料で、予告なく変更・停止することがあります。運営者は、故意または重大な過失がある場合を除き、本サービスの利用によって生じた損害について責任を負いません。

### 第8条（変更）
運営者は本規約を変更することがあります。変更後の規約は本サービス内に掲示した時点から効力を生じます。重要な変更は、事前にアプリ内でお知らせします。

### 第9条（準拠法・管轄）
本規約は日本法に準拠します。本サービスに関する紛争は、運営者の住所地を管轄する地方裁判所を第一審の専属的合意管轄裁判所とします。

## プライバシーポリシー

### 1. 運営者
バク・ジュハ（個人）。運営者の住所は、ご請求があれば遅滞なくお知らせします。

### 2. 取得する情報

| 情報 | 取得するとき | 目的 |
|---|---|---|
| 匿名アカウントID（ランダムな値） | 初めて登録・通報したとき | 自分の項目の編集・削除、利用制限、通報の処理 |
| 登録した場所・予定の内容と記述言語、登録・更新日 | 登録・更新したとき | サービスの提供（すべての利用者に公開） |
| 場所の説明、予定のタイトル・場所・内容の自動翻訳文（英語・日本語・韓国語のうち他の2言語） | 登録・更新した後 | 他の言語の利用者への表示（公開、原文も表示可） |
| 通報（対象、理由） | 通報したとき | 自動非表示と運営者の確認 |
| 書き込みの記録（いつ何を書いたか） | 書き込んだとき | 1日あたりの上限の管理 |
| 接続元IPアドレスを仮名化した値（日ごとの秘密の値を混ぜたハッシュ） | 書き込みのリクエスト時 | 不正利用の防止 |
| 運営者の措置の記録 | 運営者が非表示・削除・復元・停止したとき | 記録と監査 |

**取得しない情報:** 利用者の氏名、メールアドレス、現在地。

### 3. 位置情報
現在地は、利用者が許可したときだけ端末の中で地図の中心と徒歩時間の計算に使い、サーバーには送りません。サーバーに送る座標は、登録した場所の座標だけです。ただし、地図の画像（タイル）を読み込む際、表示している地域のタイル番号が OpenStreetMap のタイルサーバーに送られ、拡大するほど地域が絞られます。

### 4. 自動翻訳
場所の説明と、予定のタイトル・場所・内容は、登録・更新の後に Microsoft の機械翻訳（Azure AI Translator）で他の2言語に翻訳して保存し、閲覧する方の画面の言語で表示します（「自動翻訳」の表示と原文の表示があります）。Microsoft に送るのはこれらの文章と言語だけで、場所の名前、位置、予定の日時、アカウント、登録者の情報は送りません。Microsoft は、テキスト翻訳で送られた文章を保存しないと公表しています。

### 5. アクセス解析
利用状況を把握するため Cloudflare Web Analytics を使っています。Cookie は使わず、閲覧した画面、おおよその国、ブラウザ・端末の種類、読み込み速度だけを集計し、個人の識別やサイトをまたいだ追跡は行いません。

### 6. 端末に残る情報
言語設定、集めたカード、位置情報の利用の有無はブラウザの保存領域（localStorage）にだけ保存し、サーバーには送りません。ブラウザのデータを消すと消えます。

### 7. アクセスログ
本サービスを提供する事業者のサーバーには、アクセスの記録（IPアドレス、日時、ブラウザの情報など）が残ることがあります。特にアカウントサービス（Supabase Auth）の記録にはIPアドレスがそのまま残ります。保存期間は各事業者の方針によります。

### 8. 確認手続き（CAPTCHA）
自動化された攻撃があるとき、運営者は Cloudflare Turnstile による確認を有効にすることがあります。有効な間は、最初の登録時に Cloudflare が人とプログラムを区別するためにブラウザ・端末の情報を処理します。通常は無効です。

### 9. 保存期間

| 情報 | 保存期間 |
|---|---|
| 場所・予定 | 削除されるまで。削除した項目は30日後に完全に削除。終わった予定は1年後に削除 |
| 匿名アカウント | 最後の書き込み・通報から1年で削除。アカウントが削除されても登録した場所は残ります（所有者のない項目、編集不可） |
| 通報、運営者の措置の記録 | 1年 |
| 書き込みの記録 | 48時間 |
| IPアドレスの仮名化した値 | 書き込み回数の判断用は1時間、セキュリティ記録では48時間後に消去（セキュリティ記録自体は90日） |
| 自動翻訳文 | 原文と同じ: 文章を変更するとすぐに削除して翻訳し直し、場所・予定を削除するとすぐに削除 |
| バックアップ | 週1回、暗号化して90日保存。バックアップには日ごとの秘密の値が含まれないため、IPアドレスの仮名化した値を元に戻すことはできません |

### 10. 委託先と外国にある第三者
本サービスの運営のため、次の事業者に個人データの取扱いを委託しています。いずれも外国の事業者です。

| 事業者 | 委託する内容 | データの所在 |
|---|---|---|
| Supabase, Inc.（米国） | データベース、匿名アカウント | 東京リージョン |
| Cloudflare, Inc.（米国） | アプリの配信、アクセス解析、（有効時のみ）Turnstile | 世界各地の配信網 |
| GitHub, Inc.（米国） | ソースコード、暗号化したバックアップの保存（非公開） | 米国など |
| Microsoft Corporation（米国） | 場所の説明と予定の文章の自動翻訳（文章だけを送信、保存されない） | 東日本（東京）のリソースで処理 |
| OpenStreetMap Foundation（英国） | 地図の画像（利用者のブラウザが直接取得） | 英国・欧州など |

運営者は、これらの事業者が個人情報の保護に関する法律に定める基準に適合する体制を整備していることを確認したうえで委託しています。各国の個人情報の保護に関する制度については、個人情報保護委員会の提供する情報をご参照ください。

上記の委託のほか、法令に基づく場合を除き、個人データを第三者に提供しません。広告は表示しません。アクセス解析は Cookie を使わない Cloudflare Web Analytics だけです。

### 11. 安全管理
データベースは利用者の端末から直接読み書きできず、サーバー側の検査を経た機能を通してだけ書き込まれます。登録者は他の利用者に表示されず、運営者も仮名のアカウントIDしか見ません。管理者のログインにはパスワードと2段階認証を使います。バックアップは暗号化しています。

### 12. 開示・訂正・削除のご請求
アカウントが匿名のため、運営者はご請求の方がそのアカウントの持ち主であるかを確認できません。そのため、自分の項目はそのブラウザの「自分の投稿」から直接編集・削除していただくのが基本です。端末をなくした方や、アプリを使っていない方（例: 店舗の方、自宅が登録された方）は、お問い合わせから項目の名前と位置をお知らせいただければ、運営者が確認して対応します。

### 13. 変更
本ポリシーを変更するときは、本サービス内に掲示します。
