| 상태 | **초안 — 책임자 검토 전.** 게시하지 않는다 |
| 근거 | PRD-YUNABI SYS-04, Y-P1~Y-P7, Y-S12 · RFC-0003 §16 · 런북 §3.1 C-5 · 보안 점검 B-16 |

## 1. 이용약관

**1-1. 서비스.** YUNABI(이하 "서비스")는 結 -YUI- 거주자를 위한 일본어 학습, 생활 장소 지도, 일정 달력을 제공한다. 운영자는 박주하(개인)이다. (일본어판: バク・ジュハ, 영어판: Juha Bak) 이 서비스는 `[채움: 학교·과목명]` 수업 프로젝트로 지도 교원의 지도를 받아 운영한다. `[확인: 학교 이름을 적을지 — 지도 교원과 상의]` 누구나 읽을 수 있고, 장소·일정 등록과 신고에는 가입이 필요 없다(첫 등록 때 익명 계정이 자동으로 만들어진다). (Y-A1)

**1-2. 익명 계정.** 익명 계정은 사용하는 브라우저에 묶인다. 브라우저 저장소를 지우거나 기기를 바꾸면 이전에 등록한 항목을 고치거나 지울 수 없다. 이때 삭제가 필요하면 §3 의 문의로 요청할 수 있다. (Y-A2, Y-P7)

**1-3. 등록하는 내용.** 등록한 장소와 일정은 모든 사용자에게 공개된다. 다음은 등록하지 않는다.
- 자신이나 다른 사람의 집·방 위치, 이름, 연락처 등 개인을 알아볼 수 있는 정보 (Y-M7)
- 광고·스팸, 같은 내용의 반복 등록
- 법령이나 공서양속에 어긋나는 내용, 다른 사람의 권리(저작권·초상권·명예 등)를 침해하는 내용
- 사실과 다르다는 것을 알면서 쓰는 정보

**1-4. 등록한 내용의 권리.** 등록한 내용의 권리는 등록한 사람에게 남는다. 등록한 사람은 운영자가 서비스 안에서 그 내용을 보여 주고, 서비스 운영(백업·복구 포함)에 필요한 범위에서 복제·보관하는 것을 허락한다. `[확인: 이 범위로 충분한지]`

**1-5. 신고와 운영자 조치.** 사용자는 항목을 신고할 수 있다. 서로 다른 계정 3개가 신고하면 항목은 자동으로 숨겨지고 운영자가 확인한다. 운영자는 이 약관에 어긋난다고 판단한 항목을 숨기거나 삭제하고, 계정의 쓰기를 정지할 수 있다. (Y-R3, Y-R4, Y-R7)

**1-6. 이용 제한.** 짧은 시간에 많이 쓰는 것을 막기 위해 계정과 접속 단위로 쓰기 횟수를 제한한다(예: 계정당 하루 장소 등록 15건). 자동화된 대량 등록이 보이면 확인 절차(CAPTCHA)를 켤 수 있다. (Y-A3, Y-S7, D30)

**1-7. 정보의 정확성과 책임.** 장소·일정 정보는 사용자가 등록한 것이며, 운영자는 그 정확성(영업 여부, 시간, 위치 등)을 보증하지 않는다. 서비스는 무료이고 예고 없이 바뀌거나 멈출 수 있다. 운영자는 고의 또는 중대한 과실이 없는 한 서비스 이용으로 생긴 손해에 책임을 지지 않는다. `[확인: 일본 소비자계약법상 면책 범위 — "일체 책임지지 않는다" 식의 전면 면책은 무효가 될 수 있어 이 표현으로 둠]`

**1-8. 변경.** 운영자는 이 약관을 바꿀 수 있고, 바꾼 내용은 서비스 안에 게시한 때부터 효력이 있다. 중요한 변경은 앱 안에서 미리 알린다.

**1-9. 준거법·관할.** 이 약관은 일본법을 따른다. 분쟁은 운영자의 주소지를 관할하는 지방법원을 제1심 전속 관할로 한다.

**1-10. 언어.** 일본어판을 정본으로 하고, 영어·한국어판은 번역이다.

## 2. 개인정보처리방침

**2-1. 운영자.** 박주하(개인). 운영자의 주소는 요청하시면 지체 없이 알려 드린다(개인정보보호법 제32조 제1항의 "본인의 요청에 따라 지체 없이 회답하는 경우").

**2-2. 모으는 것** (Y-P1, Y-S12)

| 무엇 | 언제 | 왜 |
|---|---|---|
| 익명 계정 ID (무작위 값) | 처음 등록하거나 신고할 때 | 내 항목 수정·삭제, 이용 제한, 신고 처리 |
| 등록한 장소·일정의 내용과 작성 언어, 등록·수정 날짜 | 등록·수정할 때 | 서비스 제공 (모두에게 공개) |
| 장소 설명의 자동 번역문 (영어·일본어·한국어 중 다른 두 언어) | 설명을 등록·수정한 뒤 | 다른 언어 사용자에게 보여 주기 (모두에게 공개, 원문도 볼 수 있음) |
| 신고 (대상, 이유) | 신고할 때 | 자동 숨김과 운영자 확인 |
| 쓰기 기록 (언제 무엇을 썼는지) | 쓸 때 | 계정당 하루 한도 |
| 접속 IP 의 **가명 처리 값** (그날의 비밀 값을 섞은 해시) | 쓰기 요청 때 | 부정 이용 방지 |
| 운영자 조치 기록 | 운영자가 숨김·삭제·복원·정지할 때 | 기록과 감사 |

**모으지 않는 것:** 사용자의 이름, 이메일 주소, 현재 위치. (관리자 계정만 이메일을 쓴다.)

**2-3. 위치.** 현재 위치는 사용자가 허락한 때에만 기기 안에서 지도 중심과 도보 시간 계산에 쓰고, 서버로 보내지 않는다. 서버로 가는 좌표는 **등록한 장소의 좌표**뿐이다. 다만 지도 그림(타일)을 불러올 때 보고 있는 지역의 타일 번호가 OpenStreetMap 의 타일 서버로 가며, 확대할수록 지역이 좁혀진다. (Y-P3, ML-P3)

**2-3-2. 자동 번역.** 장소 설명은 등록·수정한 뒤 Microsoft 의 기계 번역(Azure AI Translator)으로 다른 두 언어로 번역해 보관하고, 보는 사람의 화면 언어로 보여 준다("자동 번역" 표시, 원문 보기). Microsoft 에 보내는 것은 **설명의 글과 언어뿐**이며 장소 이름, 위치, 계정, 등록자 정보는 보내지 않는다. Microsoft 는 이 서비스에서 보낸 글을 번역에만 쓰고 저장하지 않는다고 밝히고 있다. `[확인: Microsoft Translator "No Trace" 문서 링크]` (D32, ADR-0026)

**2-3-3. 방문 통계.** 앱 이용 현황을 알기 위해 Cloudflare Web Analytics 를 쓴다. 쿠키를 쓰지 않고, 방문한 화면, 대략의 국가, 브라우저·기기 종류, 로딩 속도만 모으며 개인을 식별하거나 사이트를 넘어 추적하지 않는다. (D37)

**2-4. 기기에 남는 것.** 언어 설정, 모은 카드, 위치 사용 여부는 브라우저 저장소(localStorage)에만 있고 서버로 가지 않는다. 브라우저 저장소를 지우면 사라진다.

**2-5. 접속 기록.** 서비스를 제공하는 사업자의 서버에는 접속 기록(IP 주소, 시각, 브라우저 정보 등)이 남을 수 있다. 특히 계정 서비스(Supabase Auth)의 기록에는 IP 주소가 그대로 남는다. 보관 기간은 각 사업자의 정책을 따른다. `[확인: 각 사업자의 로그 보관 기간]` (Y-P1, 인계 §2 1번 "Auth 로그에 IP 원문")

**2-6. 확인 절차 (CAPTCHA).** 자동화된 공격이 있을 때 운영자는 Cloudflare Turnstile 확인을 켤 수 있다. 켜져 있는 동안에는 첫 등록 때 Cloudflare 가 사람과 프로그램을 구별하기 위해 브라우저·기기 신호를 처리한다. 평소에는 꺼져 있다. (런북 C-5, TS-Q6)

**2-7. 보관 기간** (Y-P5, RFC §16)

| 무엇 | 보관 |
|---|---|
| 장소·일정 | 지울 때까지. 지운 항목은 30일 뒤 완전히 삭제. 끝난 일정은 1년 뒤 삭제 |
| 익명 계정 | 마지막 쓰기·신고에서 1년 → 삭제. 계정이 지워져도 등록한 장소는 남는다(주인 없는 항목, 수정 불가) |
| 신고, 운영자 조치 기록 | 1년 |
| 쓰기 기록 | 48시간 |
| IP 가명 처리 값 | 쓰기 횟수 판단용 1시간, 보안 기록에서는 48시간 뒤 지움 (보안 기록 자체는 90일) |
| 자동 번역문 | 원문과 같이: 설명을 고치면 바로 삭제하고 새로 번역, 장소를 지우면 바로 삭제 |
| 백업 | 주 1회, 암호화해 **90일** 보관. 백업에는 그날의 비밀 값이 들어가지 않아 IP 가명 처리 값을 되돌릴 수 없다 |

**2-8. 맡기는 곳과 해외** `[확인: APPI 제28조 해외 위탁 문구 — 지도 교원 검토 때 함께]`

| 사업자 | 하는 일 | 데이터가 있는 곳 |
|---|---|---|
| Supabase, Inc. (미국) | 데이터베이스, 익명 계정 | 도쿄 리전(ap-northeast-1) |
| Cloudflare, Inc. (미국) | 앱 배포·전송, 방문 통계(Web Analytics), (켤 때만) Turnstile | 세계 각지의 전송망 |
| GitHub, Inc. (미국) | 소스 코드, 암호화된 백업 보관(비공개 저장소) | 미국 등 |
| Microsoft Corporation (미국) | 장소 설명의 자동 번역(Azure AI Translator) — 글만 보내고 저장하지 않음 | `[확인: 번역기 리소스 지역, 예: 일본 동부]` |
| OpenStreetMap 재단 (영국) | 지도 그림 — 사용자의 브라우저가 직접 요청 | 영국·유럽 등 |

위 사업자에게 서비스 운영을 맡기는 것 외에, 법령에 따른 경우를 빼고 개인정보를 제3자에게 주지 않는다. 광고는 없다. 분석 도구는 쿠키 없는 Cloudflare Web Analytics(§2-3-3)뿐이다. (2026-10-29 확인: 앱의 CSP 가 외부 연결을 OpenStreetMap 타일·Supabase·Turnstile·Cloudflare Web Analytics 로만 허용한다 — `vite.config.ts`)

**2-9. 안전 관리.** 데이터베이스는 클라이언트가 직접 읽거나 쓸 수 없고 서버의 검사를 거친 함수로만 쓴다. 등록자는 다른 사용자에게 보이지 않으며, 관리자도 가명 계정 ID 만 본다. 관리자 로그인은 비밀번호와 2단계 인증을 쓴다. 백업은 암호화한다. (Y-P2, Y-S1, Y-S3, Y-S9)

**2-10. 공개·정정·삭제 요청.** 계정이 익명이라 운영자는 요청한 사람이 그 계정의 주인인지 확인할 수 없다. 그래서 자기 항목은 그 브라우저의 "내 글"에서 직접 고치거나 지우는 것이 기본이다. 기기를 잃었거나 앱을 쓰지 않는 사람(예: 가게 주인, 집이 등록된 사람)은 §3 의 문의로 **항목의 이름과 위치**를 알려 주면 운영자가 확인해 처리한다. (Y-P6, Y-P7)

**2-11. 변경.** 이 방침을 바꾸면 서비스 안에 게시한다.
