## 1. 문제 정의

**누가:** GLOBAL COMMONS 結 -YUI- 입주자 약 650명. 일본인 학생과 교환학생이 유닛을 함께 쓴다.

**무엇이 문제인가:**

| # | 문제 | 관찰 근거 (프로토타입 시나리오) |
|---|---|---|
| P1 | 생활 정보가 Instagram DM, 종이 게시판, 입소문으로 흩어져 있다 | "프런트 분실물 박스 확인해보셨어요?" 같은 정보가 댓글로만 전해진다 |
| P2 | 교환학생이 바뀔 때마다 정보가 사라진다 | 장소 추천·생활 요령이 학기마다 새로 쌓인다 |
| P3 | 세 언어 화자가 서로의 글을 읽지 못한다 | 같은 글에 일본어·영어·한국어 댓글이 섞인다 |
| P4 | 공동생활의 불만은 실명으로 말하기 어렵다 | "3층 키친 프라이팬", "노래방 예약 독점" |
| P5 | 익명은 특정인 저격으로 번질 수 있다 | 신고 예시: "5층 〇〇호실 애가 또…" |
| P6 | 교환학생이 일상 일본어(편의점, 역, 쓰레기 분리)에서 막힌다 | 일본어 에피소드 주제 |

**문제 문장:** 結 입주자는 생활에 필요한 정보를 한곳에서, 자기 언어로, 부담 없이 묻고 얻을 수 없고,
그렇게 얻은 정보도 학기가 바뀌면 사라진다.

## 2. 경쟁·대체재 분석

> 일반적으로 알려진 서비스 특성을 바탕으로 한 데스크 리서치다. 수치는 넣지 않았다.
> 입주자가 실제로 무엇을 쓰는지는 인터뷰 Q-A 블록으로 확인한다.

| 대체재 | 입주자가 쓰는 이유 | 한계 (이 문제에 대해) | YUI Board 의 차별점 |
|---|---|---|---|
| Instagram (DM, 기숙사·RA 계정) | 이미 다들 쓴다. 행사 홍보 | 실명 기반, 검색·보존 안 됨, 팔로우해야 보임 | 익명, 게시판별 정리, 기록이 남음 |
| LINE 그룹·오픈채팅 | 일본인 학생의 기본 메신저 | 흐름이 빨라 정보가 묻힘, 교환학생은 LINE 이 없는 경우도 있음, 번역 없음 | 게시판·캘린더·지도로 구조화, 번역 |
| 기숙사 종이 게시판·사무실 공지 | 공식 정보 | 그 자리에 가야 보임, 일본어·영어 위주 | 모바일, 3개 언어, .ics 내보내기 |
| 에브리타임 (한국 대학 익명 커뮤니티) | 한국 학생에게 익숙한 모델 (코드 주석에도 언급: "like 에타") | 일본 기숙사 대상이 아님 | 같은 익명 모델(글별 익명 번호)을 기숙사 단위·3개 언어로 |
| Discord / Slack 서버 | 동아리·과 단위 소통 | 가입 장벽, 채널 난립, 익명 아님 | 설치 없이 PWA, 익명 |
| Google 지도 저장 목록 | 장소 공유 | 개인 목록이라 학기 후 사라지거나 공유 범위 제한 | 結 기준 도보 시간, 입주자 큐레이션 |
| 일본어 학습 앱 (Duolingo 등) | 체계적 학습 | 기숙사·동네의 구체 장면이 없음 | "계산대에서 반드시 묻는 것", 枚方市駅 환승 같은 실제 장면 |

**포지셔닝:** 범용 메신저·SNS 와 경쟁하지 않는다. "이 건물에 사는 사람만, 익명으로, 자기 언어로"라는
좁은 범위에서 기록이 남는 공간을 만든다.

## 3. 페르소나 (가설)

### P-A 아오이 — 일본인 장기 입주자

| | |
|---|---|
| 배경 | 2학년, 結 2년째, 유닛 내 유일한 장기 거주자인 경우가 많다 |
| 언어 | 일본어 모국어, 영어 중급 |
| 목표 | 공용공간 문제를 조용히 해결하고 싶다. 교환학생과 친해지고 싶지만 먼저 말 걸기는 어렵다 |
| 불편 | 같은 질문(쓰레기 분리, 세탁기)을 학기마다 받는다. 불만을 실명으로 말하면 유닛 분위기가 어색해진다 |
| 주로 쓸 기능 | 유닛 게시판, 자유 게시판, 이벤트 |

## 4. 사용자 여정 지도 — 교환학생 한 학기 (P-B 기준, 가설)

| 단계 | 입주 전 | 입주 첫 주 | 적응기 (2~6주) | 생활기 | 귀국 준비 |
|---|---|---|---|---|---|
| 하는 일 | 기숙사 정보 검색 | 전입 신고, 장보기, 유닛 미팅 | 행사 참여, 여행, 수업 | 일상, 친구, 공용공간 문제 | 물건 처분, 작별 |
| 접점 (현재) | 학교 메일, 선배 블로그 | 사무실 안내문, 룸메이트 | Instagram, LINE 그룹 | 종이 게시판, 입소문 | Instagram 스토리, 지인 |
| 감정 | 기대 + 불안 | **혼란 (최저점)** | 들뜸, 소외감이 번갈아 | 안정 | 아쉬움, 귀찮음 |
| 페인 포인트 | 실제 생활 정보가 없다 | 일본어 서류, 어디서 사야 할지 모름 | 행사를 늦게 알게 됨, 그룹에 못 낌 | 불만을 말할 곳이 없다 | 살 사람 찾기 어려움 |
| YUI Board 기회 | (범위 밖) 설치 링크 사전 배포 | **지도(행정·생활)**, 일본어 1~2화 | **캘린더, 모집 게시판**, 번역 | 유닛·자유 게시판, 익명 | **양도 게시판 + 프로필 교환** |
| 관련 PRD | — | P-*, J-1 | C-*, B-*, L-2 | B-*, M-* | X-* |

**핵심 순간:** 입주 첫 주(정보 공백이 가장 크다)와 귀국 준비(정보가 사라지는 순간)가 제품 가치가 가장 큰 두
지점이다. 학기 시작 전후로 출시·홍보하는 것이 맞다 (→ [출시 계획](../09-release/release-plan.md)).

## 5. 검증할 가설

| # | 가설 | 틀리면 바뀌는 것 | 확인 방법 |
|---|---|---|---|
| H1 | 입주자는 공용공간 불만을 실명으로 말하기 꺼린다 | 익명 구조 전체 (가장 비싼 설계) | 인터뷰 Q-C |
| H2 | 번역이 있으면 다른 언어 글도 읽는다 | 번역 비용·구조 | 인터뷰 Q-D, 출시 후 비원어 열람 비율 |
| H3 | 교환학생은 LINE 그룹 밖에서 정보를 놓친다 | 캘린더 우선순위 | 인터뷰 Q-A |
| H4 | 귀국 전 물건 처분에 연락처 교환이 필요하다 | 프로필 교환 기능의 필요성 | 인터뷰 Q-E |
| H5 | RA 는 신고자를 알지 못하는 쪽을 선호한다 | 신고 구조 | RA 인터뷰 |
| H6 | 생활 일본어는 앱 안에서 학습할 동기가 있다 | 일본어 탭 유지 여부 | 인터뷰 Q-F, 에피소드 완독률 |
| H7 | 기숙사 사무실이 비공식 앱을 허용한다 | 출시 자체 | 사무실 면담 |

## 6. 사용자 인터뷰 가이드 (미수행)

- **대상:** 8~10명. 일본인 장기 입주자 3, 교환학생 4 (한국어권 2, 영어권 2), RA 1~2, 사무실 담당자 1
- **형식:** 30분, 1:1, 참여자 모국어 또는 영어. 녹음은 동의를 받은 경우만
- **주의:** 다른 입주자를 특정할 수 있는 이야기는 기록하지 않는다

| 블록 | 질문 |
|---|---|
| Q-A 정보 경로 | 지난주에 기숙사 생활 관련해 알아본 것이 있나요? 어디서 찾았나요? 못 찾은 것은? |
| Q-B 입주 첫 주 | 처음 들어왔을 때 가장 막막했던 것은? 누구에게 물었나요? |
| Q-C 불만 표현 | 공용공간에서 불편했던 일이 있었나요? 누군가에게 말했나요? 왜 / 왜 안 했나요? |
| Q-D 언어 | 다른 언어로 된 공지나 글을 어떻게 읽나요? 번역기를 쓰나요? |
| Q-E 거래 | 물건을 사고팔거나 넘겨본 적이 있나요? 상대를 어떻게 찾고 연락했나요? |
| Q-F 일본어 | 일본어 때문에 곤란했던 장면을 하나 떠올려 주세요 |
| Q-G 익명 | 익명 게시판이 있다면 쓰겠어요? 무엇이 걱정되나요? |
| Q-H 마무리 | 이 건물에서 다음 입주자에게 꼭 전하고 싶은 정보가 있다면? |

**인터뷰 결과 기록 템플릿:** 참여자 코드(이름 대신) / 속성 / 핵심 발언 / 관련 가설(H1~H7) 지지·반박 / 새 문제.
